# 楼盘销控可视化-Toobey

楼盘可视化程序样板：以动感视觉展示每套房的 **已售/未售状态、售价、户型、房屋图纸、装修设计参考方案**。

- **演示数据**：襄河·1号（437 套房源 + 25 栋楼 + 商铺），来自开源项目 [Ericzhu01/xianghe-sales](https://github.com/Ericzhu01/xianghe-sales)
- **技术栈**：纯 HTML + 原生 JS + CSS，无任何依赖，可离线打开，可部署任意静态托管
- **交互兼容**：桌面 Chrome + 手机微信内置浏览器双端可用

## 页面结构

| 文件 | 说明 |
|---|---|
| `index.html` | 楼盘展示首页：总平图热点（点击楼栋进销控）、户型鉴赏、KPI 统计 |
| `sales_control_v2.html` | **销控图主页面**：楼栋切换 + 每套房间状态色块（绿=已网签/黄=认购/灰=待售）+ 单价总价 + **点击房间弹窗查看户型图纸 & 装修设计参考方案** |
| `floorplan.html` | 总平图（楼栋热点直链销控图，支持 `?b=楼栋号` 定位） |
| `sales_control_show.html` | 原版销控图（保留备份，页面链接均已指向 v2） |
| `floorplans/` | 户型图纸（168/188/246/268/288.svg + jpg）与总平图 plan.jpg |
| `data/units.js` | **房源数据（换数据只改这一个文件）** |

## 核心功能

1. **已售/未售状态**：每套房一张卡片，顶部颜色条 + 状态标签（已网签=绿 / 认购=黄 / 待售=灰），楼栋切换有卡片依次入场动画，统计数字滚动。
2. **售价**：每套显示单价（元/㎡）与总价（万）；已售房显示成交价/成交总价。
3. **户型**：卡片显示户型面积，首页有户型鉴赏（5 种户型详情）。
4. **房屋图纸**：点击房间卡片 → 弹窗展示对应户型 SVG 图纸（`floorplans/{面积}.svg`，缺图自动降级 jpg 或提示补图）。
5. **装修设计参考方案**：弹窗内 5 种装修风格（现代简约/新中式/北欧原木/意式轻奢/奶油风），含配色与 **AI 装修效果图提示词（一键复制）**，并直链 roomGPT 在线生成效果图。

## 换楼盘数据（关键）

编辑 `data/units.js` 中的 `window.UNITS` 数组，每套房一个对象：

```js
{
  "building": "1#",        // 楼栋号（销控页顶部按钮按此分组）
  "room": "1602",          // 房号
  "type": "住宅",          // 住宅 / 商铺
  "layout": "188㎡",       // 户型（弹窗按此找图纸 floorplans/188.svg）
  "area": 186.84,          // 建筑面积
  "price": 7850.0,         // 挂牌单价（元/㎡）
  "total": 1466694.0,      // 挂牌总价
  "dealPrice": 0,          // 成交单价（未成交填 0）
  "dealTotal": 0,          // 成交总价（未成交填 0）
  "customer": "-",         // 客户名（非 "-" 视为认购；"已网签"则显示成交信息）
  "signDate": "",          // 网签日期
  "signStatus": "",        // 填 "已网签" → 绿色已售状态
  "invoiceStatus": "",     // 开票状态（弹窗暂未展示，可扩展）
  "receiveStatus": "",     // 收房状态（弹窗暂未展示，可扩展）
  "gift": ""               // 签约礼
}
```

状态判断逻辑（`sales_control_v2.html` 中 `getStatus()`）：
- `signStatus === '已网签'` → **已售（绿）**
- `customer !== '-'` → **认购（黄）**
- 其余 → **待售（灰）**

户型图纸：把图纸保存为 `floorplans/{面积}.svg`（如 `floorplans/188.svg`），弹窗自动匹配；商铺无图纸则显示提示。

## 本地运行

```bash
cd 本项目目录
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```
